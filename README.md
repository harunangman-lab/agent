# 중개톡 비서

공인중개사용 건축물 브리핑 웹앱입니다. HTML·CSS·JavaScript와 Node.js 기본 모듈만 사용하며 추가 패키지를 설치하지 않습니다. 로컬 PC에서 실행합니다.

## 실행

1. 이 폴더의 **실행.cmd**를 더블클릭합니다. Node.js 22 이상이 필요하며, 이 PC의 Codex 번들 Node.js도 자동으로 찾습니다.
2. 브라우저에서 **http://localhost:3000** 을 엽니다.
3. **법정동·지번** 또는 **도로명주소** 중 입력 방식을 선택합니다. 지번 방식은 시·도 → 시·군·구 → 법정동·리 → 본번·부번 순으로 입력합니다. 도로명 방식은 **주소 검색**에서 도로명주소와 연결 지번을 선택합니다. 선택 후 **건물 조회**를 누릅니다.
4. 결과가 여러 개이면 **건물·동 선택**에서 대상을 바꿉니다.

터미널에서는 이 폴더로 이동해 `npm start` 또는 `node server.mjs`를 실행하면 됩니다. 종료하려면 서버 터미널에서 Ctrl+C를 누르세요. 포트가 사용 중이면 `.env`의 `PORT=3000`을 다른 번호로 변경하고 그 포트로 접속하세요.

**가이드 예시 주소 입력** 버튼은 서울특별시 강남구 개포동 12번지를 입력할 뿐, 자동으로 조회하거나 가짜 결과를 표시하지 않습니다. 모든 결과는 실제 API 응답입니다.

## 인증키

제공된 TXT의 인증키를 이 폴더의 `.env`에 서버 환경변수 `BUILDING_API_KEY`로 설정했습니다. 키는 브라우저로 전달하지 않으며, `.env`와 원본 인증키 TXT는 상위 `.gitignore`에 등록했습니다. 상위 폴더 전체를 공개하거나 배포할 때에도 원본 TXT와 `.env`를 포함하면 안 됩니다.

다른 PC로 옮길 때는 `.env.example`을 참고해 서버의 `.env` 또는 실행 환경변수로 인증키를 설정하세요. 공공데이터포털의 일반 인증키는 인코딩·디코딩 형식 모두 지원합니다. 이 서버는 환경변수에 이미 설정된 값을 우선 사용합니다.

외부로의 통신을 제한하는 실행 환경에서는 `NETWORK_ERROR`가 발생할 수 있습니다. 일반 터미널에서 실행하고 HTTPS 연결이 허용되는지 확인하세요. 키나 API 요청 URL 전체를 로그에 남기지 않습니다.

## 실제 연동 검증

2026-11-05에 제공된 인증키로 가이드 예시 주소를 조회해 기본개요 4,339건, 표제부 34건의 정상 응답을 확인했습니다. 수치는 이후 변경될 수 있습니다.

`npm run check:api`로 인증키를 출력하지 않고 실제 연결을 재확인할 수 있습니다. 이 명령은 외부 API를 호출하므로 활용신청 승인과 인터넷 연결이 필요합니다. `npm test`는 외부 통신 없이 동작하는 자동검증입니다.

## 데이터와 처리 기준

- 기본개요: `getBrBasisOulnInfo`, 표제부: `getBrTitleInfo`.
- 요청변수: `sigunguCd`, `bjdongCd`, `platGbCd`, 4자리로 맞춘 `bun`·`ji`, `_type=json`, `numOfRows=100`, `pageNo`. 응답의 `totalCount`까지 페이지를 순회하며, 시간·페이지 한도를 넘기면 일부 결과를 완전한 결과로 표시하지 않고 오류로 안내합니다.
- 기본개요와 표제부는 같은 `mgmBldrgstPk`일 때만 결합합니다. 주소가 같다는 이유로 다른 동이나 상위 대장의 면적·세대수 등을 가져오지 않습니다.
- PK는 문자열로 보존하며 22자리 숫자형 JSON 응답도 정밀도를 잃지 않게 처리합니다. 첨부 PDF의 PK 전환 규칙은 과거 자료 연결용입니다. 신규 API가 준 PK를 임의로 다시 변환하지 않습니다.
- 빈 문자열·누락값·null은 **확인 필요**, 숫자 0은 **0**으로 표시합니다. 세대수와 가구수는 별도 항목입니다.
- 주차 합계는 `indrMechUtcnt`, `oudrMechUtcnt`, `indrAutoUtcnt`, `oudrAutoUtcnt` 네 항목이 모두 제공될 때만 계산합니다. 일부 누락 시 합계는 확인 필요로 표시하고 제공된 개별 항목은 그대로 보여줍니다.
- 승용·비상용 승강기는 각각 표시합니다. 사용승인일은 유효한 날짜일 때만 표시합니다.
- 표제부가 없으면 건물 단위의 기본개요만 표시하고 경고를 표시합니다. 전유부 각 호실을 건물 카드로 대체하지 않습니다.
- API 정보는 공적 증명서 원본이나 현장 확인을 대체하지 않습니다. 개별 호실의 전유면적·소유권·근저당·실거래 시세·위반건축물 판단은 이 버전에 포함하지 않습니다.

## 공식 지역코드

`data/regions.json`은 [행정표준코드관리시스템](https://www.code.go.kr/stdcode/regCodeL.do?menuNo=101010100010)의 **법정동코드 전체자료** ZIP에서 `존재`인 항목 20,560개만 추출했습니다. ZIP 내부 자료 기준일은 2026-10-01, 수집일은 2026-11-05입니다. 최신 실시간 목록이라고 표현하지 않습니다.

10자리 공식 코드의 앞 5자리는 시군구코드, 뒤 5자리는 API 법정동코드로 사용합니다. 읍·면 주소는 필요한 경우 해당 **리**까지 선택하세요. 세종의 상위 공식 코드도 원본 그대로 사용합니다. 첨부2의 **통합분류코드**는 이 주소 입력 코드로 사용하지 않습니다.

갱신 시 공식 ZIP을 다운로드하고 상위 폴더 `tools/import_regions.py`를 Python으로 실행하세요. 수집일 메타데이터도 실제 날짜로 갱신하고 서버를 재시작해야 합니다. 이 변환 도구는 Python 표준 라이브러리만 사용합니다. 앱 실행에는 Python이 필요하지 않습니다.

API 안내: [국토교통부 건축HUB 건축물대장정보 서비스](https://www.data.go.kr/data/15134735/openapi.do).

## 폴더

- `server.mjs`: 로컬 서버·입력 검증·정적 파일 허용목록. `127.0.0.1`에서만 수신합니다.
- `lib/buildings.mjs`: API 호출·페이지 처리·응답 정규화·오류 분류.
- `public/`: 모바일 대응 사용자 화면. 인증키를 포함하지 않으며 도로명주소 검색 시에만 공식 카카오 주소검색 스크립트를 로드합니다.
- `data/regions.json`: 출처와 기준일이 포함된 공식 코드 목록.
- `test/`: 누락·0 처리, PK 정밀도, 페이지 처리, 오류, 결합 규칙 및 지역 계층 검증.

## 도로명주소 검색

[카카오 우편번호 서비스 공식 가이드](https://postcode.map.kakao.com/guide)에 따라 별도 승인키 없이 주소검색 창을 연결했습니다. 도로명·건물명으로 검색하고 주소를 선택하면 반환된 `bcode`(10자리 법정동·리 코드)와 **선택한 `jibunAddress`의 본번·부번**으로 건축HUB를 조회합니다. 도로명주소의 건물번호를 지번으로 사용하지 않습니다.

하나의 도로명주소에 지번이 여러 개인 경우 자동으로 첫 번째 지번을 고르지 않고 사용자 선택을 요구합니다. `autoJibunAddress`는 사용하지 않습니다. 공식 코드 목록에 없는 코드나 확인되지 않는 지번은 조회를 차단하고 안내합니다. 검색 결과는 지번 단위 조회이므로 한 도로명주소의 지번에 여러 동이 있으면 결과에서 동을 선택하세요.

카카오 검색 스크립트는 **도로명주소의 주소 검색 버튼을 눌렀을 때만** 공식 CDN에서 로드합니다. 검색어는 카카오 주소검색 서비스에서 처리되며 건축HUB 인증키는 전달하지 않습니다. 외부 주소검색 서비스가 차단되거나 응답하지 않으면 지번 입력으로 계속 조회할 수 있습니다. 건축HUB API 호출은 기존처럼 로컬 서버에서만 처리합니다.

### 확인된 대표 지번 보정

2026-11-05 사용자가 알려준 **에듀시티로 148 → 대정읍 보성리 2424**를 실제 건축HUB 조회로 확인했습니다. 카카오 주소검색 결과에는 대표 지번 **2424**와 연관 지번 **2484**가 함께 있으며, 연관 지번을 선택하면 2484가 앱으로 전달됩니다. 대장 API에서 2424는 도로명주소가 에듀시티로 148인 삼정 G.edu 건물 50건, 2484는 0건이었습니다. 검색 결과의 연관 지번이 지적상 틀렸다고 단정하지 않고, 이 앱의 건축물대장 조회에는 확인된 대표 지번을 사용합니다.

따라서 `public/address.mjs`에 **법정동코드 5013025029 + 에듀시티로 148 + 연관 지번 본번 2484 / 부번 0**이 모두 일치할 때만 조회용 지번을 2424로 보정하는 검증된 예외를 등록했습니다. 화면에는 보정 사실과 확인일을 표시합니다. 다른 주소나 부번에 이 규칙을 적용하지 않으며, 다른 불일치가 발견되면 별도로 확인해야 합니다. 이 예외는 건물관리번호나 비슷한 주소로 지번을 추측하는 기능이 아닙니다.

로그인, 즐겨찾기, 안내문 생성은 이번 버전에 포함하지 않았습니다.
